# Assets Folder

Place your images here. The portfolio is pre-configured to look for these asset filenames, or you can update the paths in `index.html`:

- `profile.png` or `profile.jpg` -> Your profile photo (replaces the top-left red placeholder)
- `wizread.png` -> Preview screenshot for WizRead project
- `sadem.mp4` / `anti-drone.png` -> Dynamic real-time preview & poster for Anti-Drone RF Spectrum SPA
- `adsb.mp4` / `air-traffic.png` -> Dynamic real-time preview & poster for ADS-B Air Traffic Radar SPA
- `cv-alessandro-milos.pdf` -> Your downloadable CV / Resume

> **Note:** Whenever an image file is absent or loading, the website automatically displays the sleek red placeholder container as requested.
